# Ten-reaction paper experiment

This experiment compares two error-allocation contracts over the same fixed ten
reaction energies:

- **equal share** requires every unique species error to satisfy
  `|e_i| <= epsilon_chem / sum_j |nu_j|`;
- **reaction aware** requires only the signed reaction error
  `|sum_i nu_i e_i| <= epsilon_chem`.

Here `epsilon_chem = 1 / 627.5094740631 Ha`, exactly one kcal/mol. The
diagnostic triangle bound is `sum_i |nu_i| |e_i|`. Compiled `T` count sums
each unique species circuit once; a stoichiometric coefficient greater than one
reuses the same energy estimate.

The fixed evaluator uses Legate/cuPyNumeric on one A100 to diagonalize each
compiled one-step product-formula unitary in the full Hilbert space. For each
species it selects the lowest-energy eigenphase with numerically resolved
Hartree--Fock support and measures its signed error against the exact
fixed-electron ground energy. The exact ground-state vector is not used for PF
peak selection. The cost multiplies each species' per-attempt compiled T count
by the QPE attempts required under an equal union-bound allocation of the 5%
failure budget, guaranteeing at least 95% confidence that every unique
species peak has been observed.

## Repository boundary

- `benchmark.py` is the single authoritative registry for the ten reactions
  and their geometries, active spaces, charges, and stoichiometry.
- `inputs/` keeps the two small validated seed JSONs and hashes for 21
  external Hamiltonian-cache pairs.
- `runner/` is copied into a fresh external campaign workspace.
- `results/` accepts only a compact export that passes the final gate.

Raw campaign directories, environments, scheduler output, mutation transcripts,
and cache arrays remain external.

## Completion contract

A paper campaign contains twenty lanes: one lane per reaction and allocation
contract. Iteration 0 is the validated baseline. Iterations 1 through 50 each
evaluate one immutable proposal per lane:

```text
20 baselines + (20 lanes x 50 proposals) = 1,020 evaluated candidates
```

The final exporter rejects missing iterations, results, decisions, policy
hashes, broken parent lineage, arithmetic drift, provenance drift, or a partial
workspace. Paper selection pools candidates generated by both lane types, then
independently chooses the least-`T` candidate satisfying each contract for
each reaction.

After the gate passes, `hsopt-reports --family reactions10` creates one
`results/final/reactions/<reaction_key>/` folder per reaction. Each folder has
`extended_log.pdf` with all mutations from both source contracts and
`summary.pdf` with paired initial/final incumbents plus the separately labeled
pooled paper selections.

The preserved Omni checkpoint ends after complete iteration 13 and contains a
partial, unsafe iteration 14. It is retained externally for audit and is not a
paper result. The next campaign should start fresh with this runner.
